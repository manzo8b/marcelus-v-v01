# Release v0.7.0-risto-lab-v1 - RISTO-LAB fondazione e test

Questa release introduce **RISTO-LAB**, nuovo progetto figlio dell'ecosistema Promethea dedicato a ristorazione, bar, hospitality, formazione operativa e standard di servizio.

RISTO-LAB non nasce come generatore di prompt.

Nasce come GPT verticale per trasformare problemi reali del locale in:

- SOP;
- checklist;
- onboarding;
- corsi pratici;
- role play;
- menu knowledge;
- visual operational review;
- KPI;
- proposte formative.

## Cosa include

- cartella progetto `RISTO_LAB`;
- README dedicato;
- istruzioni Custom GPT V1;
- Builder package V1;
- conversation starters;
- starter kit;
- casi test;
- scheda feedback;
- knowledge files consigliati;
- Project Mode per uso dentro ChatGPT quando il Builder GPT non e disponibile;
- roadmap;
- issue template dedicato;
- collegamento alla macroarea Food and Beverage della Superbiblioteca;
- aggiornamento governance Promethea.

## Test

Eseguito test report pre-Builder su 10 casi:

- apertura bar non standardizzata;
- cameriere nuovo;
- cliente arrabbiato per attesa;
- menu non venduto bene;
- personale straniero B1;
- turni sbilanciati;
- checklist chiusura;
- proposta commerciale;
- foto banco bar;
- HACCP e allergeni.

Esito: **93/100 - superato con miglioramenti consigliati**.

Report:

[Test Report RISTO-LAB 2026-09-03](RISTO_LAB/TEST_REPORT_RISTO_LAB_2026_09_03.md)

## Limiti

- Il GPT live deve ancora essere creato o aggiornato nel Builder ChatGPT.
- I test sono metodologici e pre-Builder.
- Le aree HACCP, allergeni, sicurezza lavoro, diritto del lavoro, privacy e fiscalita richiedono prudenza e verifica professionale.
- RISTO-LAB non deve presentarsi come consulente normativo o certificativo.

04 / Quality & iteration

What changed, what remains to test

Observed
An earlier portfolio decision treated a changed mandatory condition as a minor revision.
Documented change
The specialized rubric now distinguishes factual or mandatory-condition errors from minor language defects. Example C is FAIL; an accent-only error remains NEEDS REVISION.
Next verification
Run and retain new V5 conversations against declared criteria. The V2 report contains one full case and a compact diagnostic batch, not 30 complete V5 transcripts.

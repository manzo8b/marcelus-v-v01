VERUM

When a clear answer changes the facts

Compare a cultural-centre description with five supplied facts and a documented correction.

Synthetic evaluation example / AI-assisted synthetic material. Not a new live GPT test or an independent human evaluation.

01 Problem02 Input & reference03 Process04 Output05 Quality check06 Evidence & limits

Problem

An answer can be easy to read while changing the information a visitor needs to make a decision. This case separates good language from reliable content.

Input & reference

Write an Italian visitor notice using only five supplied facts. The reference defines opening days, hours, price, the free-entry age and last entry.

Original Italian evidence

Original brief

Scrivi un breve testo informativo in italiano usando soltanto i fatti forniti.

Reference facts

Centro culturale aperto martedì-domenica 09:00-19:00; chiuso lunedì; biglietto ordinario 12 euro; minori di 18 anni gratis; ultimo ingresso 18:00.

Il centro culturale è aperto tutti i giorni dalle 9:00 alle 19:00. Il biglietto costa 15 euro, mentre i bambini sotto i 12 anni entrano gratuitamente. L'ultimo ingresso è consentito alle 18:30. Ti consigliamo di arrivare presto per evitare lunghe code.

Process

  1. Split the candidate into checkable attributes rather than rating its overall tone.
  2. Match each attribute to the reference and keep unsupported additions separate.
  3. Assign FAIL for substantial factual changes, then correct only the affected passages.

Output

The opening days, price, free-entry age and last entry are corrected; the unsupported queue prediction is removed. The opening hours were already preserved.

Il centro culturale è aperto da martedì a domenica dalle 09:00 alle 19:00 ed è chiuso il lunedì. Il biglietto ordinario costa 12 euro; l'ingresso è gratuito per i minori di 18 anni. L'ultimo ingresso è alle 18:00.

PASS / I cinque fatti sono preservati.

Quality check

Documentary check
The supplied reference and correction retain all five facts. The mechanical fixture test preserves the expected FAIL/PASS pair.
Documentary check
The explanation names the changed attributes rather than treating fluent Italian as factual evidence.
Human check pending
This closed-reference example does not establish live VERUM accuracy or web-search ability. A historical ambiguity regression remains unperformed.

Evidence & limits

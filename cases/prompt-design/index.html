From a vague request to an evaluation rubric

Make the criteria explicit, define severity and calibrate the decision.

Synthetic evaluation example / AI-assisted synthetic material. Not a new live GPT test or an independent human evaluation.

01 Problem02 Input & reference03 Process04 Output05 Quality check06 Evidence & limits

Problem

"Is this answer good?" hides several different decisions. Fluency, factual accuracy and compliance need separate criteria; a major error must not disappear inside an average score.

Input & reference

Turn a vague evaluation request into explicit inputs, evidence requirements and ordered decision rules. The calibration task is a neutral Italian summary, at most 20 words, with no added facts.

Original Italian evidence

Fammi un prompt per capire se una risposta AI è buona.

Original brief

Scrivi un riassunto neutro in italiano, massimo 20 parole. Non aggiungere fatti.

Reference facts

L'evento inizia alle 18:00. Ingresso gratuito. Registrazione obbligatoria.

Process

  1. Require the original instruction, reference, candidate answer and intended audience.
  2. Separate instruction adherence, factual consistency, supported content, language quality and tone.
  3. Require an exact passage and a corresponding fact or requirement for every finding.
  4. Apply severity before averaging: major error, missing evidence, minor defect, then no detected issue.

Output

A specialized evaluation prompt and four calibration examples. C changes mandatory registration into a recommendation and is FAIL; D preserves the facts but has an accent error and is NEEDS REVISION.

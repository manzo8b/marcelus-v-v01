# Custom GPT Setup Checklist RISTO-LAB V1

## Prima di creare il GPT

- [ ] Verificare nome: RISTO-LAB.
- [ ] Verificare descrizione breve.
- [ ] Copiare istruzioni Builder V1.
- [ ] Copiare 4 conversation starters.
- [ ] Preparare knowledge file generici.
- [ ] Non caricare materiali sensibili o clienti reali.

## Impostazioni consigliate

- [ ] File upload attivo.
- [ ] Analisi dati attiva.
- [ ] Web attivo se serve verifica normativa aggiornata.
- [ ] Immagini disattivate nella prima fase, salvo test visuali controllati.

## Avvertenza pubblica

Inserire una nota chiara:

```text
RISTO-LAB offre supporto operativo e formativo. Non sostituisce consulenti HACCP, RSPP, consulenti del lavoro, avvocati, commercialisti o autorita competenti.
```

## Test minimo prima della pubblicazione

- [ ] SOP chiusura bar.
- [ ] Onboarding cameriere junior.
- [ ] Menu knowledge.
- [ ] Reclamo cliente.
- [ ] Procedura allergeni con prudenza normativa.
- [ ] Visual operational review con foto non sensibile.

## Criteri di passaggio

- [ ] Risposte pratiche e non generiche.
- [ ] Procedure applicabili durante un turno reale.
- [ ] Prudenza normativa presente.
- [ ] Nessuna invenzione di obblighi, leggi o certificazioni.
- [ ] Linguaggio comprensibile per staff e manager.
- [ ] Distinzione tra fatti, ipotesi e raccomandazioni.

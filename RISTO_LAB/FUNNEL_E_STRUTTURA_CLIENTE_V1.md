# Funnel e Struttura Cliente RISTO-LAB V1

## Funnel operativo

```text
LinkedIn / GitHub / passaparola
-> primo contatto
-> discovery call 15-30 minuti
-> Quick Check o Audit
-> proposta
-> formazione
-> report
-> follow-up
-> feedback o recensione
-> nuovo intervento o caso studio anonimo
```

## Discovery call

Obiettivo: capire se RISTO-LAB puo aiutare davvero.

Domande utili:

- che tipo di locale e?
- quante persone lavorano tra sala, bar e cucina?
- qual e il problema principale oggi?
- il problema nasce da formazione, organizzazione, turni, comunicazione o controllo?
- esistono gia procedure scritte?
- ci sono menu, checklist, turni o report da analizzare?
- qual e il risultato concreto desiderato entro 30 giorni?

## Obiettivo iniziale

Prima di pensare a una scala grande, RISTO-LAB deve:

- trovare i primi clienti giusti;

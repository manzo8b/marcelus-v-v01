# Release v0.7.1-risto-lab-project-mode - RISTO-LAB Project Mode

Questa patch release aggiunge una modalita alternativa per usare RISTO-LAB quando la creazione di nuovi Custom GPT non e disponibile sull'account ChatGPT personale.

## Motivo

Al 3 settembre 2026, la documentazione ufficiale OpenAI indica che la creazione e pubblicazione di nuovi GPT non e disponibile sugli account personali Free, Go, Plus e Pro.

La creazione di GPT resta disponibile nei workspace Business, Enterprise ed Edu quando le impostazioni e i permessi lo consentono.

## Cosa cambia

- aggiunto `PROJECT_MODE_RISTO_LAB_V1.md`;
- aggiornato README RISTO-LAB;
- aggiornata checklist setup Custom GPT;
- aggiornato Builder Package;
- aggiornata release notes RISTO-LAB V1;
- aggiornato changelog.

## Uso pratico

Se non e possibile creare subito il GPT live:

1. usare un Progetto ChatGPT dedicato a RISTO-LAB;
2. incollare l'istruzione breve del Project Mode;
3. caricare solo file non sensibili;
4. testare i casi reali anonimi;
5. salvare feedback in GitHub Issues;
6. passare al Custom GPT quando sara disponibile un workspace abilitato.

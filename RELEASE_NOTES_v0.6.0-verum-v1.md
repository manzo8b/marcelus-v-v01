# Release v0.6.0-verum-v1 - VERUM V1

Questa release introduce **VERUM**, progetto figlio dell'ecosistema Promethea dedicato al fact-checking indipendente, documentato e trasparente.

VERUM e separato da Prometeus Marcelus.

Prometeus Marcelus crea prompt migliori.

VERUM analizza contenuti pubblici e produce report di verifica.

## Cosa include

- fondazione del progetto VERUM;
- naming ufficiale;
- metodo fact-checking;
- istruzioni Custom GPT V1;
- Starter Kit V1;
- 20 casi test simulati;
- scheda feedback;
- test log;
- specifica artefatto;
- builder package;
- conversation starters;
- issue template dedicato.

## Cosa non e

VERUM non e:

- un arbitro assoluto della verita;
- una testata giornalistica;
- una consulenza legale;
- uno strumento di propaganda;
- un sistema per identificare persone da immagini;
- un motore di fact-checking automatico senza verifica umana.

## Limiti

La V1 e una base metodologica e operativa.

Non contiene ancora:

- OCR reale;
- ricerca web integrata;
- database;
- esportazione PDF automatica;
- autenticazione;
- app web completa.
